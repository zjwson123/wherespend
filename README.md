# WhereSpend · 钱去哪了

> 在飞书里说一句话（文字或语音），这笔消费就被记录、分类、统计了。一笔只记一次，渠道只是属性，转账不算消费。

## 现在就能用

```bash
npm run bootstrap   # 首次：自动创建账本多维表格（已配置则跳过）
npm start           # 启动机器人 + 手机账本（长连接，无需公网 IP）
```

1. 飞书搜索机器人，私聊发 `午饭 35` —— 回执确认，账已记上
2. 手机浏览器打开日志里的 `http://<Mac的IP>:7610/?key=xxx`，添加到主屏幕
3. 日常：文字 / 按住说话 / 输入框语音输入，任选

| 想做什么 | 对机器人说 |
|---|---|
| 记一笔 | `午饭 35` `昨天打车去机场87，微信付的` `京东买书128用白条` |
| 记多笔 | `午饭35 打车12`（空格分隔） |
| 收入 / 转账 | `发工资 25000` `支付宝转银行卡 3000`（转账不计消费） |
| 查账 | `这个月花了多少` `上周外卖花了多少` |
| 改上一笔 | `改 40` `分类 购物` `用微信` `删` |

分类由 DeepSeek 自动判断（餐饮/购物/居家/交通/娱乐/医疗/人情往来/学习/宠物/其他）；模型不可用时自动回落规则解析，记账不断。

## 手机账本

- **概览**：本月支出、环比上月、分类排行、最近记录
- **明细**：时间段 × 类型 × 分类 × 账户 × 关键词任意筛选，按日分组
- **统计**：分类占比环形图、近 12 个月趋势
- 深色模式自适应；添加到主屏幕即 PWA。数据源是飞书多维表格，随时导出 CSV

## 配置（.env，已就绪）

`FEISHU_APP_ID/SECRET`（机器人）、`DEEPSEEK_API_KEY`（解析分类）、`BITABLE_APP_TOKEN/TABLE_ID`（账本，bootstrap 自动填写）、`PORT/ACCESS_KEY`（手机账本访问密钥）。
