# 飞书配置指南（WhereSpend 机器人）

> 需要具备：多维表格读写、机器人长连接收发消息、语音识别三项能力（见下方排查清单）。
> 本文用于排查权限问题与重新部署时参考。

## 快速开始（3 步）

```bash
# 1. 首次：创建账本多维表格（幂等，已在 .env 配置则跳过）
npm run bootstrap

# 2. 启动（本机即可，长连接不需要公网 IP / 域名 / 备案）
npm start

# 3. 飞书里搜索机器人名字，私聊发送：午饭 35
```

手机看账本：浏览器打开启动日志里的 `http://<Mac的IP>:7610/?key=xxx`，然后「分享 → 添加到主屏幕」。
Mac 的 IP 用 `ipconfig getifaddr en0` 查看。注意手机与 Mac 需在同一 Wi-Fi。

## 开机自启（可选）

创建 `~/Library/LaunchAgents/com.wherespend.plist`：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>com.wherespend</string>
  <key>WorkingDirectory</key><string>/path/to/wherespend</string>
  <key>ProgramArguments</key>
  <array><string>/usr/local/bin/node</string><string>src/index.js</string></array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key><string>/tmp/wherespend.log</string>
  <key>StandardErrorPath</key><string>/tmp/wherespend.err.log</string>
</dict>
</plist>
```

`launchctl load ~/Library/LaunchAgents/com.wherespend.plist`（node 路径用 `which node` 确认）。

## 开放平台控制台配置项（排查清单）

打开 [open.feishu.cn](https://open.feishu.cn) → 该应用：

| 位置 | 配置 | 用途 |
|---|---|---|
| 应用能力 → 机器人 | 已添加 | 收发消息（当前已生效） |
| 事件与回调 → 事件配置 | 订阅方式：**长连接**；事件 `im.message.receive_v1`（接收消息） | 触发记账 |
| 权限管理 | `im:message`（发送与获取消息）、`im:resource`（读取消息中的资源文件）、`speech_to_text:speech`（语音识别）、`bitable:app`（多维表格） | 各链路 |
| 版本管理与发布 | 已创建版本并发布，可用范围包含自己 | 生效前提 |

## 常见问题

- **发消息没反应**：看 `wherespend.log`。`长连接失败` → 检查事件订阅是否长连接模式；连上但无事件 → 检查是否订阅了 `im.message.receive_v1`、应用是否发布。
- **语音回执报「下载语音失败」**：权限管理里开通 `im:resource` 后重新发布版本。
- **语音回执报「语音识别失败」**：确认 `speech_to_text:speech` 权限；该接口企业标准版及以上可用。
- **写多维表格报错 91403**：机器人对表格无编辑权限 → 多维表格右上角「…」→ 添加文档应用为协作者（或直接把表格建在应用名下，用 `npm run bootstrap --force` 重建）。
- **手机打不开 7610**：同 Wi-Fi、Mac 防火墙放行 node 入站连接。
- **改密钥**：`.env` 里 `ACCESS_KEY=` 改掉重启，手机端会重新要密钥。
